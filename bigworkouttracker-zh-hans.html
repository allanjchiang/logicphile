一款不会打断你训练节奏的健身记录工具

Big Workout Tracker 采用简单、友好的界面设计，让你记录每一组动作、查看训练进度、规划下一次训练，每次打开都轻松上手。

English ・ 繁體中文

保持规律

日历让你一眼看清训练规律

每次记录训练，日历上就会显示对应的颜色，让你一眼看到整个月的训练情况。每种颜色代表你自定义的训练类型，方便你发现规律，并在漏练变成长期空档之前及时察觉。

  • ✓ 每种自定义训练类型都有专属颜色标记
  • ✓ 点击任意一天，即可查看当天的训练内容
  • ✓ 自由切换月份，回顾以往的训练记录
追踪你的进步

每个动作都有详细统计数据

你记录的每一组动作都会转化为清晰的进度图表，包括重量、次数，以及预估的单次最大重量（1RM）。选择任意动作和时间范围，从最近一周到全部训练记录，清楚看到自己的进步。

  • ✓ 重量、次数与预估 1RM 的交互式图表
  • ✓ 灵活选择时间范围，从一周到全部记录
  • ✓ 清楚掌握每个动作的长期趋势
打造你的训练计划

无限量的训练模板

根据自己的训练需求，创建不限数量的训练模板，完全按照你喜欢的方式安排。按部位、分化或训练习惯将动作分组，再通过长按拖动轻松排序。准备训练时，只需轻点一下即可开始。

  • ✓ 为你的每个训练计划创建不限数量的模板
  • ✓ 长按拖动即可重新排序动作与训练
  • ✓ 从你整理好的列表中立即开始训练
训练时掌握背景信息

训练途中也能查看历史记录

不用再猜测上次举了多重。训练进行到一半时，打开任意动作的历史记录，即可查看之前的组数、次数与重量，在最需要的时刻获取信息，让你更有把握地决定如何进步。

  • ✓ 无需离开当前训练，即可查看过去的组数与次数
  • ✓ 一眼看到每个动作此前的最佳表现
  • ✓ 实时掌握信息，做出更明智的重量与次数决定
